## Suggested study order

If pursuing all three: **SAA-C03 → DVA-C03 → MLA-C02**. SAA-C03 builds the architecture
vocabulary (networking, security, storage, databases) that both DVA-C03 and MLA-C02 assume.
DVA-C03 deepens the hands-on/application layer. MLA-C02 then layers ML-specific services on
top of infrastructure you already understand.

Each cert's own README has the full domain breakdown, task statements, in/out-of-scope service
lists, and a study-order checklist for its domains.
